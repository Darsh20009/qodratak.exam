Keep one clear student preparation path personalized to observed level, exam date and available daily time. The user reported getting lost in the platform despite being its creator; more separate tools are not a substitute for clear next steps.

**Why:** The user explicitly requested a connected daily course, not scattered tasks, tests and reports.

**How to apply:** Make the next task primary and supplementary tools optional. Explain weak/slow observations with evidence, keep reviewed source keys authoritative, and never promise completing the entire bank or a perfect official score when time/evidence does not support it.

Tahsili is not ready for student use. Keep its student-facing lessons, tests and plans closed and labeled «قريبًا» until the user explicitly asks to reopen it after readiness work.

**Why:** The user said «المنصة التحصيلي لا يعمل بالكامل» and requested closing anything related to it.

**How to apply:** Preserve existing content, administrative maintenance and historical results; do not delete Tahsili data. Apply availability restrictions on the server as well as navigation so direct student URLs do not reopen unfinished features.
