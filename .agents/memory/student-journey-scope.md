---
name: Student journey and Tahsili availability
description: Product scope for a focused student dashboard, consolidated account page, and safe Tahsili availability.
---

Keep one clear student preparation path personalized to observed level, exam date and available daily time. The user reported getting lost in the platform despite being its creator; more separate tools are not a substitute for clear next steps.

**Why:** The user explicitly requested a connected daily course, not scattered tasks, tests and reports.

**How to apply:** Make the next task primary and supplementary tools optional. Explain weak/slow observations with evidence, keep reviewed source keys authoritative, and never promise completing the entire bank or a perfect official score when time/evidence does not support it.

Keep the student's first dashboard view short and action-first; long instructions, the guide film, feedback form and detailed coaching should be optional disclosures.

**Why:** The user explicitly said the dashboard had become too crowded with text, including after adding onboarding explanations.

**How to apply:** Preserve access to these tools and the guide's hide/restore setting, but do not force the student to read them before reaching the next task.

Keep student account details, subscription status, platform rating, and payment history/invoices on «حسابي», not in the dashboard. Make reviews and payment history collapsible so the page stays compact.

**Why:** On 2026-10-15, the user asked to reduce dashboard clutter and gather account-related details in one place.

**How to apply:** Use the account page as the home for personal and billing information; keep the dashboard centered on the next learning action.

Keep Qudrat test types together under «الاختبارات» inside «المحوسب», including simulations, models and scheduled simulation booking.

**Why:** The user explicitly asked for one section containing every Qudrat exam type rather than scattered entry points.

**How to apply:** Add future Qudrat exam entry points to this hub while retaining existing routes. A hub link is not evidence that reviewed exam content is available; state missing content clearly.

Course reading tasks must identify the specific teaching unit, not allocate a short slot to an entire book. Confirming a unit's reading must not complete the whole book or assert mastery.

**Why:** The persona audit exposed 15–22 minute assignments pointing to 150–180 minute books without a section target. Students could not tell what they were expected to finish.

**How to apply:** Keep unit reading self-reported and separate from trusted practice results and whole-content completion. Source difficulty labels and text-based lesson matches are instructional hints, not calibrated difficulty or approved concept mastery.

Tahsili student pages are released, but only real resources and questions with reviewed answer keys may be shown. Do not label the whole program «قريبًا» or make tests from unreviewed OCR drafts.

**Why:** On 2026-10-15, the user explicitly reversed the earlier closure request and asked for Tahsili to be available; question-key accuracy remains a stated requirement.

**How to apply:** Let eligible students open uploaded source files and released Tahsili pages. Use only reviewed, verified questions for tests; keep pending OCR drafts in admin review. If there are no approved questions, explain that accurately rather than showing a generic «قريبًا» message.

Use «التأسيس» as the single student-facing destination for preparation. Inside it, keep distinct «القدرات» and «التحصيلي» tracks, and expose each track’s foundation materials and plan together; do not add a separate main-navigation page named «خطتي».

**Why:** The user explicitly corrected the navigation: the student should choose the program under «التأسيس» and find that program’s content and plan there.

**How to apply:** Keep legacy plan URLs routed into the corresponding track’s plan view and keep Tahsili materials reachable from its foundation track rather than requiring a separate study destination.

The «عرض كل صفحات المنصة» shortcut on the student dashboard must reveal a visible page directory on both desktop and mobile, not silently toggle a desktop sidebar while only opening a drawer on mobile.

**Why:** The user reported that the shortcut did nothing on larger screens.

**How to apply:** When changing the student page directory, verify its visible open state at desktop and mobile breakpoints.

Students without a booked exam must be able to start assessment and daily learning without inventing an official exam date.

**Why:** Booking is not a prerequisite for beginning preparation; a fabricated deadline would distort urgency and the student's course.

**How to apply:** Open a daily session only when a real ready plan exists; otherwise explicitly offer published foundation material, not a fabricated personalized session or a request to wait for nonexistent new content. Intro visibility and booking-choice preferences are presentation only, never evidence of level or permission to bypass assessment/subscription checks.

Keep «المزيد» a searchable directory of all active student-facing pages on desktop and mobile, with clear learning-goal shortcuts. Do not expose admin routes, context-only exam routes, or unavailable content as ready.

**Why:** The user explicitly asked to make every remaining student page discoverable and to improve the learning experience for students at every level.

**How to apply:** Add new student-ready destinations to the shared navigation registry and verify each link resolves to a route; preserve subscription checks and distinguish published Tahsili resources from questions still awaiting review.

The Tahsili experience needs a connected foundation-and-computerized course, not just a PDF library and an exam link. Build it in stages using published source units, subject-specific practice, and reviewed question keys.

**Why:** The user explicitly said both the Tahsili foundation and computerized courses need substantial development and requested that work proceed in phases.

**How to apply:** Organize available materials by subject and lesson, connect each lesson to practice and a useful result, and do not claim missing videos or unreviewed questions are ready.
