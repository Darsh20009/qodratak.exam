---
name: Computerized exam boundary
description: Product boundary for computerized Qudrat bank, section, comprehensive, and mixed exams.
---

All computerized exams must use the shared Qiyas exam frame, including a quiz attached to a foundation or bank lesson. Do not add a second inline exam renderer for a new bank or section.

**Why:** Students should have one consistent navigation, timing, answer-selection, report, and review experience. Duplicated exam shells drift and make it unclear which result is authoritative.

**How to apply:** Route new bank and section entry points into the existing frame. When imported questions include original images, show those images as the authoritative visual and use OCR/text only as supporting data; do not score questions whose answer key is still ambiguous.
