---
name: Customer complaint notification boundary
description: Why complaint alerts are minimal admin notices, separate from saving customer tickets.
---

Use WhatsApp for an admin arrival notice, not automatic customer messages or forwarding full complaint/contact records.

**Why:** The requested flow sends complaints to administration. Complaints can contain private information; the protected admin interface remains the place to read the full record. A notification outage must not cause a successfully saved complaint to appear unsuccessful.

**How to apply:** Use the existing configured administration recipient and a minimal reference/name notice. Keep full complaint details and contact information in the authenticated admin interface, and distinguish ticket-save success from notification delivery.
