---
name: Daily study integrity
description: Rules for trusted daily goals, study streaks, and active study-time measurement.
---

A study day is complete only when unique, server-verified answered questions reach the student's configured daily target for the Saudi calendar date. Viewing a question does not count as an answer. Preserve historical counters, but keep them separate from verified progress.

**Why:** The user requested progress that reflects real learning activity, not page opens or old counters that may have been collected under different rules.

**How to apply:** Derive verified answers from approved server-owned answer keys, deduplicate a question within the same Saudi day, and calculate streaks from saved verified completion. Count study time only for an authenticated student on a visible learning route; exclude exams and avoid crediting duplicate or long-gap heartbeats.
