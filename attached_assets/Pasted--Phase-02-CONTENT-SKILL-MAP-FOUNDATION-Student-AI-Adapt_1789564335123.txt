ابدأ الآن Phase 02 فقط:

# CONTENT & SKILL MAP FOUNDATION

مهم جدًا:

لا تبدأ ببناء Student AI/Adaptive Engine الآن.

لا تبدأ بتحليل الطلاب.

لا تغير الواجهة الحالية.

لا تنشئ Dashboard جديد.

لا تضف Chatbot.

لا تضف Floating Assistant.

لا تظهر أي تقنية أو AI للطالب.

هدف هذه المرحلة هو بناء "خريطة المعرفة" التي ستعتمد عليها المنصة لاحقًا لفهم الطالب.

━━━━━━━━━━━━━━━━━━━━

1. اعتمد على الموجود أولًا
   ━━━━━━━━━━━━━━━━━━━━

راجع:

* Question Bank الحالي
* Courses الحالية
* Subjects الحالية
* Topics الموجودة
* Question metadata
* Existing categories
* Existing explanations

لا تفترض أن البيانات الحالية منظمة بشكل صحيح.

أريد معرفة ما يمكن إعادة استخدامه.

━━━━━━━━━━━━━━━━━━━━
2. أنشئ Conceptual Learning Hierarchy
━━━━━━━━━━━━━━━━━━━━

نحتاج بنية قابلة للتوسع:

Program
→ Subject
→ Topic
→ Skill
→ SubSkill
→ Concept
→ Question

مثال:

قدرات
→ كمي
→ النسب
→ النسبة المئوية
→ الزيادة والنقصان
→ مفهوم حساب النسبة
→ Questions

ومثال لفظي:

قدرات
→ لفظي
→ التناظر اللفظي
→ العلاقات
→ علاقة الجزء بالكل
→ Concept
→ Questions

هذه مجرد أمثلة.

لا تخترع منهجًا كاملًا من عندك إذا لم يكن المحتوى موجودًا.

استخرج الموجود أولًا ثم اقترح النواقص.

━━━━━━━━━━━━━━━━━━━━
3. قدرات — Verbal
━━━━━━━━━━━━━━━━━━━━

جهز Architecture لدعم المهارات الموجودة في بنك الأسئلة.

مثل:

التناظر اللفظي
إكمال الجمل
الخطأ السياقي
استيعاب المقروء
المفردات
العلاقات اللفظية

لكن لا تعتبر هذه القائمة نهائية.

استخرج التصنيفات الفعلية من المشروع والمصادر الموجودة.

━━━━━━━━━━━━━━━━━━━━
4. قدرات — Quantitative
━━━━━━━━━━━━━━━━━━━━

ابنِ نفس الهيكل للكمي.

يجب أن نستطيع الوصول إلى مستوى دقيق جدًا.

مثال:

كمي
→ الكسور
→ العمليات على الكسور
→ جمع الكسور
→ Concept

أو:

كمي
→ النسب
→ النسبة المئوية
→ الزيادة والنقصان
→ Concept

الفكرة:

إذا أخطأ الطالب في سؤال، نستطيع معرفة المهارة والمفهوم الدقيق الذي ارتبط به السؤال.

━━━━━━━━━━━━━━━━━━━━
5. التحصيلي
━━━━━━━━━━━━━━━━━━━━

جهز Architecture مستقبلية للتحصيلي بدون تنفيذ تجربة الطالب الآن.

يجب أن تكون البنية قادرة على دعم:

الرياضيات
الفيزياء
الكيمياء
الأحياء

مع:

Subject
→ Topic
→ Skill
→ SubSkill
→ Concept
→ Question

لا نحتاج الآن لبناء كل محتوى التحصيلي إذا لم يكن موجودًا.

نحتاج فقط أن تكون Architecture قابلة لاستيعابه.

━━━━━━━━━━━━━━━━━━━━
6. Question Mapping
━━━━━━━━━━━━━━━━━━━━

هذه أهم مهمة في Phase 02.

خذ الأسئلة الموجودة وحاول ربط كل سؤال بـ:

program
subject
topic
skill
subSkill
concept
difficulty
prerequisites

إذا كانت بعض البيانات غير موجودة:

لا تخمن بشكل أعمى.

أنشئ:

Needs Review

أو:

Unmapped

حتى يستطيع Admin مراجعتها لاحقًا.

━━━━━━━━━━━━━━━━━━━━
7. Prerequisites
━━━━━━━━━━━━━━━━━━━━

أريد أن تكون المهارات مترابطة.

مثال:

الكسور
↓
النسب
↓
النسبة المئوية
↓
الزيادة والنقصان
↓
المسائل التطبيقية

إذا كان Concept يعتمد على Concept آخر، خزّن هذه العلاقة.

لكن لا تنشئ علاقات وهمية.

ابدأ فقط بالعلاقات التي يمكن إثباتها من المحتوى الحالي.

━━━━━━━━━━━━━━━━━━━━
8. Difficulty
━━━━━━━━━━━━━━━━━━━━

لا تعتمد فقط على:

Easy
Medium
Hard

صمم النظام بحيث يمكن تطويره لاحقًا إلى:

difficulty
estimatedTime
successRate
discrimination

لكن في هذه المرحلة لا تحاول حساب الإحصائيات التي تحتاج بيانات طلاب حقيقية.

━━━━━━━━━━━━━━━━━━━━
9. Database Design
━━━━━━━━━━━━━━━━━━━━

صمم Schema نظيفة وقابلة للتوسع.

يمكن أن تشمل:

Program
Subject
Topic
Skill
SubSkill
Concept

مع العلاقات اللازمة.

قبل إضافة Schema جديدة:

راجع الـ Database الحالية.

إذا كانت هناك Collections/Tables تؤدي نفس الوظيفة:

لا تنشئ نسخة ثانية بدون سبب.

قدم Migration Strategy بدل duplication.

━━━━━━━━━━━━━━━━━━━━
10. Admin Content Mapping
━━━━━━━━━━━━━━━━━━━━

إذا كان بنك الأسئلة الحالي يحتاج تصنيفًا يدويًا، جهز Architecture تسمح للإدارة لاحقًا بـ:

تحديد Subject
تحديد Topic
تحديد Skill
تحديد SubSkill
تحديد Concept
تحديد Difficulty
تحديد Prerequisites

لكن لا تحتاج لبناء واجهة Admin كاملة في هذه المرحلة إلا إذا كانت ضرورية.

━━━━━━━━━━━━━━━━━━━━
11. أهم قاعدة
━━━━━━━━━━━━━━━━━━━━

لا تجعل:

Question = Skill فقط.

نحتاج مستوى أعمق:

Question
→ Concept

لأن النظام لاحقًا يجب أن يعرف:

"الطالب أخطأ في هذا السؤال"

ثم:

"السؤال مرتبط بهذا المفهوم"

ثم:

"المفهوم يحتاج هذه المهارة"

ثم يستطيع النظام أن يقرر:

هل يعيد السؤال؟

أم يشرح المفهوم؟

أم يرجع لمهارة سابقة؟

━━━━━━━━━━━━━━━━━━━━

بعد الانتهاء:

أعطني فقط:

1. ما الذي وجدته؟
2. ما هي خريطة المحتوى التي أصبحت موجودة؟
3. كم سؤال تم تصنيفه؟
4. كم سؤال بقي Unmapped؟
5. ما الـSchemas التي تم إنشاؤها أو تعديلها؟
6. هل حدث أي Migration؟
7. نتيجة typecheck/lint/tests.
8. ما الذي تقترحه للـPhase 03؟
