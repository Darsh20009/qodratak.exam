## Security

اختبر أيضًا:

### Student A

يستطيع:

* إنشاء annotation
* قراءتها
* تعديلها
* حذفها

### Student B

لا يستطيع:

* قراءة annotation الخاصة بـA
* تعديل annotation الخاصة بـA
* حذف annotation الخاصة بـA

يجب أن تعود النتيجة المناسبة حسب architecture الحالية، مثل `404` أو `403`.

لا تقبل:

`studentId`

من body أو query.

## Content Scope

اختبر أن annotation مرتبطة بـ:

* contentId
* contentVersion
* sectionId

وأن section غير موجود يتم رفضه.

اختبر أيضًا version safety:

* annotation على current version تعمل.
* محاولة mutation على old version يتم رفضها.
* annotation القديمة لا يتم حذفها تلقائيًا.

## Validation

اختبر:

* invalid annotation type
* invalid coordinates
* oversized drawing
* oversized note
* invalid section
* invalid content
* unauthenticated request → `401`
