# منصة قدراتك — Qudratuk

![شعار منصة قدراتك](generated-icon.png)

منصة قدراتك هي منصة تعليمية عربية متخصصة في إعداد الطلاب لاختبارات القدرات والتحصيلي في المملكة العربية السعودية. المشروع مُدار ويُطوّر تحت هوية **Qirox Studio**، ويدعم واجهة عربية كاملة باتجاه RTL.

## ماذا يقدم النظام؟

- تسجيل المستخدمين وتسجيل الدخول والجلسات الآمنة.
- تجربة مجانية وعضويات مدفوعة وإدارة الاشتراكات.
- بنك أسئلة مصنف مع الشروحات والتلميحات والإشارات المرجعية.
- اختبارات لفظية وكمية واختبارات محاكية واختبارات مجدولة.
- نتائج وتحليلات أداء ولوحة متصدرين ونظام نقاط.
- تحديات جماعية وغرف مذاكرة وتواصل دعم فني مباشر.
- مساعد ذكاء اصطناعي لشرح الأسئلة وتحليل الأداء وبناء خطط مذاكرة.
- تسجيل دخول حيوي وPIN وميزات حماية إضافية.
- لوحة تحكم إدارية لإدارة المستخدمين والأسئلة والاشتراكات والإعلانات والدعم والإعدادات والمحافظ.
- دعم البريد الإلكتروني والإشعارات والدفع بحسب الخدمات المفعّلة في البيئة.

## التقنية والبنية

- **الواجهة:** React 18 وTypeScript وVite وTailwind CSS وshadcn/ui.
- **الخادم:** Node.js وExpress وTypeScript.
- **البيانات:** MongoDB كقاعدة رئيسية، مع PostgreSQL للبيانات التي تحتاج إلى Drizzle.
- **الجلسات:** Express Session مع MongoDB Store.
- **الاختبارات:** Vitest غير مستخدم؛ التحقق الأساسي يتم عبر TypeScript وVite وESBuild.
- **النشر:** يوجد إعداد `render.yaml` وأوامر Docker وFly.io قابلة للتكييف مع مزود النشر المختار.

## التشغيل المحلي

يتطلب المشروع Node.js 20 أو أحدث:

```bash
npm ci
npm run dev
```

يفتح الخادم على المنفذ `5000` افتراضيًا. لبناء نسخة الإنتاج:

```bash
npm run build
npm start
```

## متغيرات البيئة

انسخ أسماء المتغيرات التالية إلى مدير الأسرار في بيئة التشغيل، ولا تضع القيم الحقيقية في Git:

```env
NODE_ENV=development
PORT=5000
SESSION_SECRET=
MONGODB_URI=
DATABASE_URL=
APP_URL=
ADMIN_EMAIL=qoudratak@gmail.com
ADMIN_INITIAL_PASSWORD=
WEBAUTHN_ORIGIN=
WEBAUTHN_RP_ID=
OPENAI_API_KEY=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
SMTP_HOST=
SMTP_PORT=
SMTP_USER=
SMTP_PASS=
SMTP_FROM=
SMTP2GO_API_KEY=
FROM_EMAIL=noreply@qodratak.site
FROM_NAME=منصة قدراتك
VAPID_PUBLIC_KEY=
VAPID_PRIVATE_KEY=
VAPID_EMAIL=
TELEGRAM_BOT_TOKEN=

```

ليست كل الخدمات إلزامية للتشغيل الأساسي؛ تُستخدم كل خدمة عند تفعيل الميزة المرتبطة بها. يجب ضبط `APP_URL` و/أو `WEBAUTHN_ORIGIN` و`WEBAUTHN_RP_ID` عند استخدام WebAuthn أو OAuth في الإنتاج.

## دخول لوحة الإدارة

صفحة الإدارة:

```text
/admin/login
```

يتم التحقق من حساب المدير من MongoDB. في التثبيت الأول ينشئ النظام حساب المدير الافتراضي الموجود في `server/mongodb/mongoStorage.ts`. اضبط `ADMIN_INITIAL_PASSWORD` في مدير الأسرار قبل أول تشغيل، ثم غيّر كلمة المرور فورًا بعد أول دخول. إذا لم تضبط المتغير فسيستخدم النظام قيمة مؤقتة موجودة في الكود للتوافق المحلي فقط؛ لا تستخدمها في الإنتاج. لا تحفظ أي كلمة مرور في README أو في مستودع عام. يمكن إنشاء مدراء إضافيين من قسم **الأدوار والصلاحيات** داخل لوحة التحكم.

## البريد والدعم

البريد التشغيلي المعلن للمنصة هو:

```text
qoudratak@gmail.com
```

يتم تحديد مزود الإرسال وبياناته من خلال متغيرات البيئة فقط. لا تُحفظ كلمات مرور البريد أو مفاتيح مزود الإرسال داخل الكود.

## النشر عبر Render

ملف `render.yaml` يعرّف خدمة Node تلقائيًا:

1. اربط هذا المستودع بحساب Render.
2. تأكد من استخدام `npm ci && npm run build` للبناء و`npm run start` للتشغيل.
3. أضف متغيرات البيئة المطلوبة من القائمة أعلاه في إعدادات Render.
4. راجع سجلات البناء والتشغيل بعد النشر.

يوجد شرح إضافي باللغة العربية في [DEPLOY.md](DEPLOY.md).

## هيكل المشروع

```text
client/          واجهة React والصفحات والمكونات
server/          خادم Express والمسارات والخدمات
server/mongodb/  نماذج وتخزين MongoDB
shared/          الأنواع والمخططات المشتركة
public/          ملفات PWA والأيقونات والملفات العامة
uploads/         الصور المرفوعة أثناء التشغيل
```

## الأمان

- لا ترفع ملفات `.env` أو مفاتيح API أو كلمات المرور أو بيانات المستخدمين.
- لا تضع بيانات الاعتماد في رسائل commit أو ملفات التوثيق العامة.
- استخدم مدير الأسرار في مزود النشر.
- فعّل HTTPS واضبط `APP_URL` في الإنتاج.
- غيّر بيانات المدير الافتراضية فورًا، وراجع صلاحيات المدراء دوريًا.
